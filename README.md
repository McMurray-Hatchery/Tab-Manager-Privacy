# Privacy Policy

Last updated: September 29, 2026

## Tab Manager Chrome Extension

Tab Manager is a Chrome extension that helps users reduce duplicate browser tabs by reusing an existing tab when a newly opened URL matches a configured URL pattern.

## Data Collection

Tab Manager does not collect, sell, transmit, or share any personal data.

The extension works locally in the user’s browser. It does not use remote servers, analytics, tracking tools, advertising tools, or third-party services.

## URL and Tab Access

Tab Manager may read open tab URLs only to determine whether a URL matches a configured pattern. This is required for the extension’s single purpose: finding and reusing an existing matching tab instead of opening a duplicate tab.

The extension does not collect or store browsing history on any external server.

## Storage

Tab Manager uses Chrome storage to save user-configured URL patterns. These patterns are stored locally through Chrome’s extension storage system so the extension can remember which websites should reuse existing tabs.

## Data Sharing

Tab Manager does not sell, transfer, or share user data with third parties.
